## Remaining

- Make `just precommit` cheaper past `bats -j` and the parallel shellcheck (59 s down to about 20 s, load 4 to 6 on 4 cores, 2026-11-06). The largest remaining cost `bats --timing` showed is the `_verdict_path_read` timing case (19 s, untraced; the timings it prints are under 0.4 s).
- A checkout whose only refusal is git's `warning:` unlink of a file the target deleted (exit 0, HEAD moved, file left untracked) gives no `partial=1`, so the `readonly-path` verdict prints the bare re-run act and no recovery clause. Cause recorded in `docs/references/readonly-path.md`; a fix adds that message to the partial-checkout needles, with a fixture cut from `git checkout markdown`-style corpus hits.
- A checkout refused with `Operation not permitted` gets no `readonly-path` verdict: the matcher takes only the read-only-filesystem and busy-device messages (`lib/matchers.sh` ~147). Recorded case: `git checkout unification`, `-Users-david-code-edify`, 2026-01-22, exit 0 with HEAD moved. Whether this message should fire needs its own corpus check, since it has other causes than the sandbox; the README already marks the macOS sandbox's own messages unverified.
- The `phantom-gitadd` verdict (`lib/verdicts.sh`, `manual/detectors.md`) says to re-run unsandboxed with no wait, while `phantom-chardev` and the lock `mask` verdict carry a qualifier about no sandboxed command running alongside. A probe on 2026-11-06 (CC 2.1.318, Linux) could not reproduce the refusal: masks now land as zero-byte read-only regular files, not character devices, and `git add` stages those without complaint; masks also land only in the directory a sandboxed call starts in, so a subagent cannot put them in a scratch repo. The probe needs the main session (its cwd persists) and a sandbox that still lays character-device masks; compare an immediate re-run with one while a backgrounded sandboxed command is alive, since the siblings' qualifier is about a concurrent command.
- Masks are now zero-byte read-only regular files (seen 2026-11-06, CC 2.1.318, Linux, in the main tree and in worktrees). If they outlive the sandboxed call, an unsandboxed `git add -A` stages every non-ignored one (`.claude/launch.json`, `.claude/commands`, ...) instead of failing, and no verdict says so; the probe saw them unsandboxed while sibling agents' sandboxed calls were live, so persistence is unsettled. Probe it with no other session running, then decide whether `phantom-gitadd` and `docs/references/` need a regular-file branch.
- Propose a guard: a check that no `SKILL.md` matches either of Claude Code's own expansion patterns, the inline one (an exclamation mark, after a line start or whitespace, before a backtick) and the fenced one (a three-backtick fence opened with an exclamation mark); both read from the CC 2.1.319 binary on 2026-11-06. Claude Code ran one as a shell command and refused to load the skill (fixed 2026-11-06); nothing stops it coming back.
- `tests/verdicts-readonly-path.bats`' `_verdict_path_read` timing case still uses wall seconds (`perf_counter`, about line 231). `tests/probes-readonly-tokenize-time.bats` moved to CPU seconds after load turned it red twice on 2026-11-05; this case has not been seen failing, so check whether it can before changing it.
- `tests/probes-readonly-tokenize-time.bats` still runs its cases one at a time (`BATS_NO_PARALLELIZE_WITHIN_FILE`) so a dense case is not timed against a plain word that ran without it. A review's probes on 2026-11-05 found CPU ratios barely move under one-sided load, so the setting may no longer earn its serial cost. Running the cases in parallel is untried.
- A code commit got slower: `gate-code` took 195 s where the pre-split gate took 173 s, both forced on the same machine on 2026-11-05 with 5 to 8 load. `tests/gate-coverage.bats` now builds its scratch tree once and copies it per case, which took it from 70 to 80 s to 58 to 64 s under `bats -j 8` at load 9 to 17; `tests/task-files-cache.bats` still builds it per case, in five of its six cases, about 1 min serial. A prose commit dropped to about 49 s.
